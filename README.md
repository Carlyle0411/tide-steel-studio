# 赤霆宇宙素材生成库

English name: Crimson Tempest Universe Asset Library

本库服务于 AI 科幻短剧宇宙项目《潮汐钢魂：赤霆纪元》，用于长期沉淀世界观、机甲、巨兽、角色、驾驶舱、HUD、场景、动作镜头、剧本、提示词、音频和剪辑交付资产。

## 项目目标

- 建立一套可持续更新的 AI 影视生产资产库。
- 保证赤霆-01、白潮、林舟、许燃、AI澜等核心资产在多平台生成时保持一致。
- 降低可灵、即梦、Runway、Pika、Luma 等工具的试错成本。
- 将图片生成、图生视频、分镜执行、剪映字幕、配音、质检纳入统一流程。

## 使用方式

1. 先阅读 `ASSET_LIBRARY_SPEC.md`，确认命名、分组、版本、提示词和归档规范。
2. 在对应资产目录中选择设定文档和提示词模板。
3. 先生成关键帧，再生成短镜头视频。
4. 每个镜头产出后登记到 `15_TEMPLATE模板文件/asset_inventory.csv` 或对应剧集执行表。
5. 成片、废弃版本、旧提示词统一归档到 `99_ARCHIVE归档`。

## 标准工作流

1. 明确剧集目标：剧情钩子、角色关系、核心奇观。
2. 选定资产：角色、机甲、怪兽、场景、HUD、音频。
3. 生成首帧：优先保证主体结构、标志特征、文字清晰。
4. 图生视频：每个镜头先做 5 秒测试，再扩展到 7 秒、15 秒或 30 秒。
5. 导出剪辑包：字幕、旁白、镜头提示词、音效建议、后期备注。
6. 质检归档：保留最终版本，废弃素材进入归档区并记录原因。
